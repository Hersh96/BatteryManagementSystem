Deployment & Setup

Everything needed to run the project locally, move it to Raspberry Pi, use real sensors, and publish the project on GitHub.

Setup Steps

01 Windows Demo

Run scripts/setup_windows.ps1, then scripts/run_windows.ps1. This installs Python dependencies and pulls qwen3:0.6b.

02 Raspberry Pi

Run bash scripts/setup_pi.sh, then bash scripts/run_pi.sh. The default mode still uses simulated telemetry.

03 Hardware Mode

Set BATTERY_AI_SENSOR=ina219 and install adafruit-circuitpython-ina219 after wiring the sensor safely.

04 GitHub

Source, docs, tests, and GitHub Actions are ready. Generated logs, databases, caches, and model files are ignored.

Commands

# Windows
scripts\setup_windows.ps1
scripts\run_windows.ps1

# Raspberry Pi / Linux
bash scripts/setup_pi.sh
bash scripts/run_pi.sh

# Real sensor mode
BATTERY_AI_SENSOR=ina219 BATTERY_AI_LLM_PROVIDER=ollama python -m edge_battery_ai.server
