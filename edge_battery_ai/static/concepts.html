Purpose of the Project

The goal is to build a low-cost edge AI battery diagnostics system. A Raspberry Pi measures battery behavior locally, estimates health from real telemetry, and uses a small local language model to explain the result. The important engineering idea is separation of responsibility: sensors measure, deterministic code calculates, and the LLM explains.

Core Concepts

Edge Intelligence
Local sensing + local reasoning
The Pi runs the app and model without cloud inference.
Telemetry
Voltage, current, power, temperature
Samples are collected continuously and stored as session data.
Capacity Integration
mAh and Wh over time
Battery capacity is computed from current and timestamps.
LLM Report
Explanation, not measurement
The model turns structured facts into readable diagnosis text.

Why the LLM is Not the Calculator

# Good architecture
sensor readings -> analytics.py -> structured facts -> llm.py -> readable report

# Avoid this
sensor readings -> LLM guesses battery health

# Reason
Battery health should come from measured capacity, energy, temperature, and rules.
The language model is used for communication, not as the source of truth.
