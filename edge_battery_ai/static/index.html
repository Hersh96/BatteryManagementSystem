      Hardware

      The project runs without hardware in simulator mode. For the edge build, use a Raspberry Pi 5, an INA219/INA226 current sensor, a temperature probe, and a protected battery test circuit.

      • Raspberry Pi 4/5 with 4GB or 8GB RAM
      • INA219, INA226, or USB meter with serial output
      • DS18B20/BME280 temperature sensor
      • Battery holder, charger/load module, fuse, and BMS

      AI Model

      The downloaded model is Qwen3 0.6B through Ollama. The model receives structured facts from the analytics engine and writes a concise diagnosis. It does not invent raw measurements.

      BATTERY_AI_LLM_PROVIDER=ollama BATTERY_AI_MODEL=qwen3:0.6b

      Runbook

      From laptop demo to Raspberry Pi

      01

      Install dependencies

      python -m pip install -r requirements.txt
      02

      Download model

      ollama pull qwen3:0.6b
      03

      Run app

      python -m edge_battery_ai.server
      04

      Use hardware mode

      BATTERY_AI_SENSOR=ina219
